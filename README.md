# Romeo & Juliet — Two Texts, One Stage

A static reading companion that presents Shakespeare's original beside the supplied modern-English text, with clickable explanations of poetic and literary devices.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. The site uses no build step and no external runtime dependencies.

## Contents

- `play-data.js` — paired passages extracted from the supplied *No Fear Shakespeare: Romeo and Juliet* PDF.
- `devices.js` — contextual notes and a quick device glossary.
- `app.js` and `styles.css` — reader interactions and responsive layout.

The modern-English text is from the supplied *No Fear Shakespeare* edition by SparkNotes. The original play is by William Shakespeare.
